## Start here: the big picture

The introduction

1. [SPECTRUM – The Invisible Entity We Can't Do Without](https://research.samsung.com/blog/SPECTRUM-THE-INVISIBLE-ENTITY-WE-CAN-T-DO-WITHOUT) - What radio spectrum is and why it is a scarce resource.
2. [Fundamentals of Wireless Signals and Cellular Networks](https://www.qualcomm.com/developer/blog/2019/10/fundamentals-wireless-signals-and-cellular-networks) - A gentle introduction to wireless signals and how cellular networks are organized.
3. [The Bit. How Claude Shannon Defined Information and Why It Still Powers Every AI System](https://medium.com/@EleventhHourEnthusiast/the-bit-how-claude-shannon-defined-information-and-why-it-still-powers-every-ai-system-d806b5ff1438) - A Medium article about Shannon's theory
4. [From Shannon to Modern AI: A Complete Information Theory Guide for Machine Learning](https://machinelearningmastery.com/from-shannon-to-modern-ai-a-complete-information-theory-guide-for-machine-learning/) - How Shannon’s information theory connects to the tools you’ll find in modern machine learning

## Fundamentals of wireless communications

1. [A Mathematical Theory of Communication](https://people.math.harvard.edu/~ctm/home/text/others/shannon/entropy/entropy.pdf) - Shannon's 1948 paper on information, entropy, and channel capacity.
2. [Wireless Communications](https://web.stanford.edu/class/ee359/doc/WirelessComm_Chp1-16_March32020.pdf) - Wireless Communications by Andrea Goldsmith
3. [Digital Communications](https://daskalakispiros.com/files/Ebooks/digital-communication-proakis-salehi-5th-edition.pdf) - Digital Communications by Proakis and Salehi

## MIMO, mMIMO, XL-MIMO, CF-MIMO, HMIMO
1. [MIMO Wireless Communication](https://archive.ll.mit.edu/publications/journal/pdf/vol15_no1/15_1mimo.pdf) - A survey about the environmental factors that affect MIMO capacity
2. [Massive MIMO Networks: Spectral, Energy, and Hardware Efficiency](https://massivemimobook.com/wp/free-pdf/) - A complete book on mMIMO. In the respective website one can find simulation code too.
3. [A Tutorial on Near-Field XL-MIMO Communications Towards 6G](https://arxiv.org/html/2310.11044v3) - A thorough overview of Near-Field XL-MIMO Communications

## Hands on
1. [Deep MIMO](https://www.deepmimo.net/) - Deep MIMO dataset and scenarios
2. [Sionna library](https://developer.nvidia.com/sionna) - NVIDIA GPU-accelerated open-source library for research in communication systems
3. [NeoRadium](https://github.com/InterDigitalInc/NeoRadium) - Python library for simulating end-to-end wireless communication systems based on the latest 3GPP 5G NR standards
4. [Emil Björnson's GitHub](https://github.com/emilbjornson) - Professor Emil Björnson has the richest GitHub page regarding cutting edge research on wireless communications
5. [How to Design an Antenna That Actually Works](https://www.fedevel.com/blog/how-to-design-an-antenna-that-actually-works-all-steps-explained) - Good example of antenna design using CST
